# XP&UP: дашборд регистраций

Веб-приложение для регистрации участников и анализа данных. Не требует установки пакетов: только Python 3.9+ (внутри SQLite и стандартный веб-сервер).

## Запуск

Двойной щелчок по `run.bat` или в терминале:

```bash
python app/server.py
```

Откройте http://127.0.0.1:8000/. Пароль администратора сервер создаёт при первом запуске, печатает в консоль и сохраняет в `data/admin_password.txt`. Свой пароль задаётся в файле `.env` (скопируйте `.env.example`) переменной `ADMIN_PASSWORD`.

Чтобы посмотреть дашборд на примере, нажмите «Показать на демо-данных» на пустом экране или выполните `python app/server.py --seed-demo`. Демо-записи помечены «демо» и удаляются одной кнопкой.

## Страницы

| Адрес | Что это | Доступ |
|---|---|---|
| `/` | Дашборд: показатели, графики, таблица, импорт и экспорт CSV | по паролю |
| `/register` | Публичная форма регистрации для участников | открыта |

Источник регистрации берётся из ссылки: `/register?source=telegram` запишет «telegram». Без параметра будет «Сайт». Так видно, какой канал приводит больше участников.

## Подключение к вашему сайту

Есть два способа.

1. **Ссылка или iframe на `/register`.** Самый простой вариант.
2. **Своя форма на сайте.** Отправьте JSON на `POST /api/register`:

```js
fetch("https://ВАШ-АДРЕС/api/register", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ name: "Анна Иванова", email: "anna@example.com", city: "Москва", age: 27, track: "Дизайн", source: "Сайт" })
});
```

Если сайт на другом домене, укажите его в `.env`: `CORS_ORIGIN=https://ваш-сайт`. Новая заявка всегда получает статус «Ожидает», администратор подтверждает её в дашборде. Повторный email возвращает ошибку 409. Лимит: 10 заявок в час с одного адреса.

## API для администратора

Нужен вход (`POST /api/login` с `{"password": "..."}`, дальше работает cookie).

| Метод и адрес | Действие |
|---|---|
| `GET /api/participants` | все участники и число мест |
| `POST /api/participants` | добавить участника |
| `PATCH /api/participants/<id>` | сменить статус (`pending`, `confirmed`, `cancelled`) |
| `DELETE /api/participants/<id>` | удалить |
| `POST /api/participants/import` | массовый импорт `{"items": [...]}`, дубли по email пропускаются |
| `PUT /api/settings` | число мест `{"capacity": 200}` |
| `GET /api/export.csv` | выгрузка всех участников |
| `POST` / `DELETE /api/demo` | добавить / удалить демо-данные |

## Безопасность

- Данные участников видны только после входа. Пароль проверяется на сервере, вход ограничен 8 попытками за 5 минут.
- Сессия лежит в `HttpOnly`-cookie с `SameSite=Strict`. На хостинге с HTTPS включите `COOKIE_SECURE=true`.
- В форме регистрации стоит скрытое поле-ловушка для ботов и лимит частоты.
- Страница дашборда отдаётся с политикой CSP, внешнему коду выполняться нельзя.
- Это встроенный сервер Python. Для публичного сайта с большим трафиком поставьте перед ним nginx или Caddy с HTTPS (тогда `TRUST_PROXY=true`).

## Данные и резервные копии

Всё лежит в папке `data/`: `registrations.db` (SQLite), `secret.key`, `admin_password.txt`. Для резервной копии остановите сервер и скопируйте эту папку. Папка исключена из git.
